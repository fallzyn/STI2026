## Nome

Fila Mack.

## Problema

O setor acadêmico precisa controlar a fila de atendimento.

## Objetivo

Construir um sistema para emitir e chamar senhas.

## Usuários

- Aluno.
- Atendente.

## Escopo

- emissão de senhas;
- chamada de senhas;
- finalização de atendimento;
- visualização da fila.

## Fora do escopo

- cadastro de aluno ou autenticação;
- persistência após recarga da página, armazenamento em banco de dados ou qualquer mecanismo de persistência externa;
- filas prioritárias, múltiplos atendentes ou atendimento concorrente;
- uso de bibliotecas externas, frameworks ou tecnologias de frontend mais complexas do que HTML, CSS e JavaScript;
- requisitos de produção, integrações externas e manutenção de dados entre sessões.

## Restrições técnicas

- aplicação de página única;
- implementação em HTML, CSS e JavaScript sem bibliotecas externas;
- dados mantidos apenas em memória durante a sessão do navegador;
- sem autenticação, banco de dados, cadastro de aluno, prioridade de senha ou atendimento concorrente;
- uma única fila e um único atendente operando a aplicação.
